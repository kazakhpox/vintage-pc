# Vintage PC — компьютер из 2000-х для Minecraft (NeoForge 1.21.1)

Блок «Ретро-компьютер». Правый клик открывает экран монитора: внутри Chromium (MCEF) запущена оболочка в стиле Windows 98. Выход — **Shift+Esc**: обычный Esc остаётся играм.

## Архитектура

```
 Слой 1  Оболочка (HTML/CSS/JS, 98.css): окна, «Пуск», Блокнот, Сапёр, WinPopup, Сетевое окружение
 Слой 2  Игры: WASM-порты (iframe из games/), эмулятор v86 с Win9x/DOS, Webamp
 Сеть    JS ⇄ ws://127.0.0.1 (мост в моде) ⇄ пакеты Minecraft ⇄ сервер-коммутатор ⇄ другие игроки
```

## Мультиплеер по «локальной сети» на сервере Minecraft

Сервер Minecraft работает как сетевой свитч. Внешние порты, VPN и Hamachi не нужны: всё идёт внутри обычного соединения с сервером. Работает на выделенном сервере, в одиночном мире и в мире, открытом через «Открыть для сети».

* **Рабочая группа** («Сетевое окружение» → поле «Рабочая группа»). Компьютеры с одинаковым именем группы находятся в одной LAN. Там же виден список чужих ПК, их ники, виртуальные IP и то, что они хостят.
* Типы каналов:
  * `eth:<сеть>` — обучаемый L2-свитч для сырых Ethernet-кадров. В v86 к нему подключена NE2000, поэтому IPX (Heroes III, Red Alert, Warcraft II, Doom) и TCP/IP работают как в настоящей локалке.
  * `room:<имя>` — широковещательная комната для JS-игр, чата и лобби.
  * `VPCNet.udp(name)` — виртуальный UDP с адресами `10.98.x.y`, через него WASM-порты (Xash3D, ioquake3 и т. п.) подключают свои сокеты.
* Защита сервера: не больше 200 пакетов и 256 КБ за тик на игрока, не больше 16 каналов, кадры до 16 КБ. Пакеты помечены как optional, поэтому на сервер с модом можно зайти и без мода.
* Если у игрока несколько ПК, они делят одну подписку на канал и видят друг друга локально.

### JS-API для своих игр

В игре, запущенной из `games/`, подключите `../../web/vpc-net.js` (параметры сети приходят в URL):

```js
const room = VPCNet.room('my-game');          // JSON-сообщения всем в комнате
room.on((msg, sender) => ...); room.send({ x: 1 });
const sock = VPCNet.udp('my-game', pkt => ...); sock.sendto('255.255.255.255', 27015, bytes);
```

Пример сетевой игры: `web/apps/tictactoe.js` (крестики-нолики по LAN).

## Установка контента

При первом запуске создаётся папка `.minecraft/vintagepc/`:

| Путь | Что положить |
|---|---|
| `games/games.js` | список ярлыков: `window.VPC_GAMES = [{ name, icon, url, lan }]` |
| `games/v86/` | `libv86.js`, `v86.wasm`, `seabios.bin`, `vgabios.bin`, `config.js` с образом диска |
| `games/webamp/` | `webamp.bundle.min.js`, `playlist.js` (`window.WEBAMP_TRACKS = [...]`) |
| `games/<игра>/` | WASM-порт (reVC, Xash3D-FWGS, ioquake3, PrBoom…) |

Данные коммерческих игр (GTA VC, Half-Life, Q3A и т. д.) мод не распространяет: берите их из своих лицензионных копий.

## Сборка

Нужны JDK 21 и Gradle 8.8+:

```bash
gradle wrapper && ./gradlew build
```

Для проверки LAN запустите два клиента и сервер: `./gradlew runServer`, `runClient`, `runClient2`.

MCEF: в `gradle.properties` сверьте `mcef_*` с актуальной NeoForge-сборкой MCEF или MCEF Modern. Если у вашей сборки другой пакет, поправьте импорты в `client/BrowserPool.java` и `client/PcScreen.java`.
